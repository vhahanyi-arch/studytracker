# Unit 1 — Number and calculation

Cambridge Lower Secondary Mathematics, Stage 9, objectives 9Ni.01, 9Ni.02 and 9Ni.04. See [source and scope](README.md).

## Key ideas

### Rational and irrational numbers — 9Ni.01

A **rational** number can be written as a fraction a/b of two integers (b not zero). Its decimal either stops (0.375 = 3/8) or repeats (0.272727... = 3/11). Integers are rational too: 6 = 6/1.

An **irrational** number cannot be written as a fraction. Its decimal goes on for ever without repeating. Examples: π, √2, √3, √10 and any square root of a positive integer that is not a square number. √16 = 4 is rational, because 16 is a square number; √(9/4) = 3/2 is rational too.

### Indices, including negative and zero — 9Ni.02

For any non-zero base a:

- aᵐ × aⁿ = aᵐ⁺ⁿ (add indices when multiplying);
- aᵐ ÷ aⁿ = aᵐ⁻ⁿ (subtract indices when dividing);
- (aᵐ)ⁿ = aᵐⁿ (multiply indices for a power of a power);
- a⁰ = 1;
- a⁻ⁿ = 1/aⁿ, so a negative index means "one over".

These follow from the dividing law: 2³ ÷ 2⁵ = 2⁻² and also = 8/32 = 1/4, so 2⁻² = 1/4.

### Estimating surds — 9Ni.04

A surd is a root that is irrational, such as √50. Estimate it by finding the square numbers (or cube numbers) on either side:

- √50: 49 = 7² and 64 = 8², so √50 is between 7 and 8, much closer to 7: about 7.1.
- ∛100: 64 = 4³ and 125 = 5³, so ∛100 is between 4 and 5: about 4.6.

Learn the squares to 15² and the cubes to 5³ (and 10³ = 1000).

## Key facts and formulas

| Fact or formula | What it means | When to use it |
|---|---|---|
| aᵐ × aⁿ = aᵐ⁺ⁿ; aᵐ ÷ aⁿ = aᵐ⁻ⁿ | Add or subtract indices, same base | Simplifying powers. |
| (aᵐ)ⁿ = aᵐⁿ | Multiply indices | A power of a power. |
| a⁰ = 1; a⁻ⁿ = 1/aⁿ | Zero and negative indices | Small numbers, reciprocals, standard form. |
| Rational: terminates or recurs; irrational: neither | Decimal behaviour | Classifying numbers. |
| √n lies between the square roots of the squares either side of n | Bounds for a surd | Estimating roots without a calculator. |

## Using the methods in different situations

### Situation: classifying numbers

**Example.** Which are irrational: √36, √37, 0.121212..., π, 22/7? Only √37 and π. √36 = 6; 0.121212... recurs, so it is rational (= 4/33); 22/7 is a fraction, so rational (it is only close to π).

**Example — a product.** √2 × √8 = √16 = 4: two irrational numbers can multiply to give a rational one.

### Situation: negative and zero indices

**Example — evaluate.** 2⁻³ = 1/2³ = 1/8. 10⁻² = 1/100 = 0.01. 5⁰ = 1. (1/3)⁻² = 3² = 9.

**Example — simplify.** 3⁴ × 3⁻⁶ = 3⁻² = 1/9. 7⁵ ÷ 7⁸ = 7⁻³. (5²)³ = 5⁶. (2³)⁻¹ = 2⁻³ = 1/8.

**Example — find the index.** 2ˣ = 1/32. Since 32 = 2⁵, x = −5.

### Situation: estimating surds

**Example — between which integers?** √75: 64 < 75 < 81, so 8 < √75 < 9. 75 is nearer 81, so √75 is about 8.7 (calculator: 8.66).

**Example — closer estimate.** √30: between 5 (25) and 6 (36), about halfway, so about 5.5 (calculator: 5.48).

**Example — cube root.** ∛100 is between 4 and 5. 100 is nearer 125 than 64 in value, but cubes grow quickly, so about 4.6 (calculator: 4.64).

### Situation: order of operations with indices

**Example.** 5 × 2⁻² + 3⁰ = 5 × 1/4 + 1 = 1.25 + 1 = 2.25.

## Common mistakes

- Thinking a negative index makes a negative number: 2⁻³ is 1/8, not −8.
- Thinking a⁰ = 0. It is 1.
- Adding indices for a power of a power: (5²)³ is 5⁶, not 5⁵.
- Calling 22/7 or 3.14 irrational: they are rational approximations of π.
- Saying every square root is irrational: √49 = 7 is rational.
