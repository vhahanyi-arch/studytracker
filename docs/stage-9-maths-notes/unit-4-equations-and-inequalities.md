# Unit 4 — Equations and inequalities

Cambridge Lower Secondary Mathematics, Stage 9, objectives 9Ae.05, 9Ae.06 and 9Ae.07. See [source and scope](README.md).

## Key ideas

### Forming and solving equations — 9Ae.05

Solve by doing the same to both sides. Expand brackets first; clear fractions by multiplying both sides by the denominator (or by the lowest common multiple of several denominators).

When the unknown is in the denominator, as in 12/x = 3, multiply both sides by the denominator (here x) to bring it to the top: 12 = 3x. Then solve as usual.

To form an equation from a problem, choose a letter for the unknown, write expressions for the quantities, and set up the equality the problem describes. Check the solution in the problem, not just in the equation.

### Simultaneous linear equations — 9Ae.06

Two equations with two unknowns, both true at once. Methods:

- **Elimination:** add or subtract the equations to remove one unknown. If needed, first multiply one or both equations so the coefficients of one unknown match.
- **Substitution:** if one equation gives y = … (or x = …), substitute it into the other.
- **Graphically:** draw both lines. The solution is the point where they cross.

Always substitute both values back into both original equations to check.

### Linear inequalities — 9Ae.07

Solve an inequality like an equation, with one extra rule: **multiplying or dividing both sides by a negative number reverses the inequality sign**. Show the answer on a number line: an open circle for < or >, a filled circle for ≤ or ≥.

A double inequality such as 1 < 2x + 3 ≤ 9 is solved by doing the same to all three parts.

## Key facts and formulas

| Fact or method | What it means | When to use it |
|---|---|---|
| Multiply both sides by the denominator | Clears fractions | Equations with fractions, including an unknown in the denominator. |
| Elimination: match a coefficient, then add or subtract | Removes one unknown | Simultaneous equations. |
| Substitution: replace y with its expression | Reduces to one unknown | When one equation is already y = … |
| Solution = intersection of the two lines | Graphical method | Simultaneous equations from graphs. |
| × or ÷ by a negative reverses the sign | −2x < 6 gives x > −3 | Inequalities. |

## Using the methods in different situations

### Situation: fractions on both sides

**Example.** (x + 3)/4 = (x − 1)/2. Multiply both sides by 4: x + 3 = 2(x − 1) = 2x − 2. So x = 5. Check: 8/4 = 2 and 4/2 = 2.

### Situation: unknown in the denominator

**Example.** 12/x = 3: multiply by x, 12 = 3x, so x = 4.

**Example — with a bracket.** 15/(x + 2) = 3: 15 = 3(x + 2) = 3x + 6, so 3x = 9 and x = 3.

**Example — extra term.** 6/x + 1 = 4: 6/x = 3, so 6 = 3x and x = 2.

### Situation: simultaneous equations by elimination

**Example — add.** 2x + y = 11 and x − y = 1. Adding removes y: 3x = 12, so x = 4. Then 4 − y = 1, so y = 3. Check: 2 × 4 + 3 = 11.

**Example — multiply first.** 3x + 2y = 16 and 2x + 5y = 18. Multiply the first by 2 and the second by 3: 6x + 4y = 32 and 6x + 15y = 54. Subtract: 11y = 22, so y = 2. Then 3x + 4 = 16, so x = 4.

### Situation: simultaneous equations by substitution

**Example.** y = 2x − 1 and 3x + y = 14. Substitute: 3x + 2x − 1 = 14, so 5x = 15, x = 3 and y = 5.

### Situation: a word problem

**Example — tickets.** 2 adult and 3 child tickets cost $31; 1 adult and 4 child tickets cost $28. Let a and c be the prices: 2a + 3c = 31 and a + 4c = 28. From the second, a = 28 − 4c. Substitute: 2(28 − 4c) + 3c = 31, so 56 − 5c = 31 and c = 5. Then a = 8. Adult tickets cost $8 and child tickets $5.

### Situation: simultaneous equations from a graph

**Example.** The lines y = x + 1 and y = 7 − x cross at (3, 4), so the solution is x = 3, y = 4. Check: 3 + 1 = 4 and 7 − 3 = 4.

### Situation: solving inequalities

**Example.** 3x − 4 < 11: 3x < 15, so x < 5.

**Example — reversing the sign.** −2x ≤ 8: divide by −2 and reverse: x ≥ −4.

**Example — double inequality.** 1 < 2x + 3 ≤ 9: subtract 3, −2 < 2x ≤ 6; divide by 2, −1 < x ≤ 3. The integer solutions are 0, 1, 2 and 3.

**Example — forming one.** A rectangle is x cm by 6 cm and its perimeter must be at most 40 cm: 2x + 12 ≤ 40, so x ≤ 14.

## Common mistakes

- Multiplying only one term by the denominator when clearing fractions.
- Forgetting to reverse the inequality when dividing by a negative number.
- Subtracting when the signs mean you should add (or the other way round) in elimination.
- Finding x but not y in simultaneous equations.
- Using a filled circle for < or an open circle for ≤.
