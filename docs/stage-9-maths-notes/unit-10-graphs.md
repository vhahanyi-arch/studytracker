# Unit 10 — Graphs

Cambridge Lower Secondary Mathematics, Stage 9, objectives 9As.04, 9As.05 and 9As.06. See [source and scope](README.md).

## Key ideas

### Linear functions from words — 9As.04

A linear relationship can be written as y = mx + c (explicit form) or ax + by = c (implicit form). Situations with a fixed amount plus a rate give y = mx + c. Situations where two quantities share a total give the implicit form: "adult tickets cost $5, child tickets $2, and $40 was spent in total" is 5x + 2y = 40.

### Tables, graphs and quadratic graphs — 9As.05

For a linear graph, find at least three points. For an implicit equation such as 2x + 3y = 12, the quickest points are the intercepts: put x = 0 to find where it crosses the y-axis, and y = 0 for the x-axis.

A quadratic function has an x² term, such as y = x² − 2x − 3. Its graph is a smooth U-shaped curve (a parabola), symmetric about a vertical line through its lowest point (or highest point if the x² term is negative). Draw it from a table of values with a smooth curve, not straight lines between points.

### Equation of a straight line — 9As.06

To find the equation y = mx + c of a line:

- gradient m = change in y ÷ change in x between two points; it can be negative or a fraction;
- substitute one point into y = mx + c to find c.

Parallel lines have the same gradient. A line's gradient can also be read by rearranging its equation into y = mx + c.

## Key facts and formulas

| Formula | What it means | When to use it |
|---|---|---|
| y = mx + c | Explicit form: gradient m, y-intercept c | Reading gradient and intercept. |
| ax + by = c | Implicit form | Situations with a total; rearrange to y = mx + c for the gradient. |
| m = (y₂ − y₁) ÷ (x₂ − x₁) | Gradient from two points | Equation of a line. |
| x-intercept: y = 0; y-intercept: x = 0 | Where the graph crosses the axes | Quick plotting. |
| y = ax² + bx + c makes a parabola | Quadratic graph | Drawing quadratic graphs. |

## Using the methods in different situations

### Situation: writing a function from words

**Example — implicit form.** Pens cost $3 and notebooks $4; Mia spends exactly $24. If x is pens and y notebooks: 3x + 4y = 24. Possible whole-number purchases: (0, 6), (4, 3) and (8, 0).

### Situation: implicit to explicit

**Example.** 2x + 3y = 12. Subtract 2x: 3y = −2x + 12. Divide by 3: y = −2/3 x + 4. Gradient −2/3, y-intercept 4. Intercepts: (0, 4) and (6, 0).

### Situation: a quadratic graph

**Example.** y = x² − 2x − 3 for x from −2 to 4:

| x | −2 | −1 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|---|---|
| y | 5 | 0 | −3 | −4 | −3 | 0 | 5 |

The curve is symmetric about x = 1, with lowest point (1, −4). It crosses the x-axis at x = −1 and x = 3, and the y-axis at −3.

**Example — careful substitution.** At x = −2: (−2)² − 2(−2) − 3 = 4 + 4 − 3 = 5.

### Situation: equation from two points

**Example — negative fractional gradient.** A line passes through (−2, 5) and (4, 2). m = (2 − 5) ÷ (4 − (−2)) = −3 ÷ 6 = −1/2. Using (4, 2): 2 = −1/2 × 4 + c, so c = 4. The equation is y = −1/2 x + 4.

### Situation: parallel line through a point

**Example.** A line is parallel to y = 3x − 1 and passes through (2, 9). Gradient 3: 9 = 3 × 2 + c, so c = 3. The equation is y = 3x + 3.

### Situation: reading a graph

**Example.** On the graph of y = x² − 2x − 3, the solutions of x² − 2x − 3 = 0 are where the curve crosses the x-axis: x = −1 and x = 3.

## Common mistakes

- Reading the gradient of 2x + 3y = 12 as 2: rearrange to y = mx + c first.
- Joining the points of a quadratic graph with straight lines, or making a pointed bottom.
- Squaring a negative x without brackets: (−2)² = 4, not −4.
- Swapping change in x and change in y in the gradient.
- Losing the sign when the gradient is negative.
