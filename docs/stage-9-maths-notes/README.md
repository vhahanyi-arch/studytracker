# Stage 9 mathematics revision notes

Summary notes for the 15 Stage 9 practice units of Cambridge Lower Secondary Mathematics (0862), one file per unit. They follow the objective list in [lib/lower-secondary/framework.ts](../../lib/lower-secondary/framework.ts), which gives every Stage 9 learning-objective code and the unit it belongs to. The notes are written in our own words; no Cambridge text or test questions are copied into them.

Each unit has the same shape: key ideas (each heading cites its objective codes), a table of key facts and formulas, worked examples of each method in different kinds of question, and common mistakes. Notation matches the practice questions: mixed numbers as 2 1/3, recurring decimals as 0.333...

To change a note, edit the markdown here and run `pnpm notes`. `tests/notes/content.test.ts` fails if the generated module and these files disagree, if a unit lacks notes, or if a unit's notes do not cite each of its objective codes.
