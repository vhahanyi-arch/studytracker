# Unit 2 — Expressions, formulae and equations

Cambridge Lower Secondary Mathematics, Stage 8, objectives 8Ae.01 to 8Ae.07. See [source and scope](README.md).

## Key ideas

### What letters mean — 8Ae.01

- An **expression** is a collection of terms with no equals sign: 3x + 2.
- A **formula** is a rule connecting quantities, where each letter stands for something: A = lw (area = length × width). Substituting values for some letters gives the other.
- An **equation** is true only for particular values of the unknown: 3x + 2 = 11 is true only when x = 3.

In an expression or formula, a letter is a variable: it can take many values. In an equation, it is an unknown to find.

### Simplifying with the laws of arithmetic — 8Ae.02

Like terms have exactly the same letters and powers: 3a and −a are like terms; x and x² are not. Collect like terms by adding their coefficients. The order of multiplication does not matter, so multiply the numbers, then the letters:

- a × a = a², a × a × a = a³;
- 2a × 3a = 6a²; 4x × x² = 4x³;
- 12x³ ÷ 4x = 3x².

### Expanding and factorising — 8Ae.03

Expanding multiplies every term inside the bracket by the term outside: 3(2x − 5) = 6x − 15 and x(x² + 4) = x³ + 4x. Watch the signs: −2(3 − y) = −6 + 2y.

Factorising is the reverse: take out the highest common factor (HCF) of all the terms, numbers and letters, and put what is left in the bracket. 12x + 18 = 6(2x + 3). Check by expanding.

### Turning words into expressions — 8Ae.04

Read the words in order and decide what happens to the number. "Five less than half of n" is n/2 − 5, which can also be written ½n − 5. "Three times the sum of n and 4" is 3(n + 4). Reverse it too: 2(n − 1) means "subtract 1 from n, then double".

### Formulae and changing the subject — 8Ae.05

To write a formula from words, choose a letter for each quantity and say what each letter means. To use a formula, substitute and follow BIDMAS. To change the subject, undo the operations around the letter you want, doing the same to both sides, in the reverse order to how they were applied.

### Forming and solving equations — 8Ae.06

Solve by doing the same to both sides until the unknown is alone. With the unknown on both sides, first move the smaller x-term so you keep a positive x. Multiply both sides to clear a fraction. Always check by substituting your answer into the original equation.

To form an equation, write an expression for the quantity the problem gives a value for, and set it equal to that value.

### Intervals — 8Ae.07

A letter can stand for every number in an interval, not just one number.

- x > 3: all numbers greater than 3, but not 3 itself. The end is **open** (an open circle on a number line).
- x ≤ 5: all numbers up to and including 5. The end is **closed** (a filled circle).
- −2 ≤ x < 4: between −2 and 4, including −2 but not 4. The integers in it are −2, −1, 0, 1, 2 and 3.

## Key facts and formulas

| Fact or method | What it means | When to use it |
|---|---|---|
| a × a = a², a × a × a = a³ | Repeated multiplication of a letter | Simplifying products of terms. |
| k(a + b) = ka + kb | Multiply every term in the bracket | Expanding a single bracket. |
| Take out the HCF | 12x + 18 = 6(2x + 3) | Factorising. |
| Do the same to both sides | Keep the equation balanced | Solving equations and changing the subject. |
| Undo in reverse order | Last operation applied is the first undone | Solving and rearranging. |
| Open end (<, >) and closed end (≤, ≥) | Whether the end value is included | Writing and reading intervals. |

## Using the methods in different situations

### Situation: simplifying

**Example — collect like terms.** 3a + 5b − a + 2b = 2a + 7b.

**Example — squares kept separate.** 2x² + 3x − x² + x = x² + 4x.

**Example — products and quotients.** 2a × 3a = 6a². 5y × 2y² = 10y³. 18m³ ÷ 6m = 3m².

### Situation: expanding and factorising

**Example — expand.** 4(3x + 2) = 12x + 8. x(x + 7) = x² + 7x. −3(2a − 5) = −6a + 15.

**Example — expand and simplify.** 2(x + 3) + 5(x − 1) = 2x + 6 + 5x − 5 = 7x + 1.

**Example — factorise.** 15a − 20 = 5(3a − 4). x² + 5x = x(x + 5). 6a² − 9a = 3a(2a − 3).

### Situation: words to expressions and formulae

**Example — a number puzzle.** "Think of a number n, multiply by 3, subtract 4" gives 3n − 4.

**Example — a cost formula.** Concert tickets cost $8 each plus a $3 booking fee per order. For n tickets the cost C is C = 8n + 3. For 5 tickets, C = 8 × 5 + 3 = 43, so $43.

### Situation: substituting into a formula

**Example.** v = u + at with u = 4, a = 3 and t = 5: v = 4 + 3 × 5 = 19.

**Example — with negatives.** p = 2q − r² with q = −3 and r = 4: p = 2 × (−3) − 16 = −22.

### Situation: changing the subject

**Example — two steps.** Make t the subject of v = u + at. Subtract u: v − u = at. Divide by a: t = (v − u)/a.

**Example — a bracket.** Make w the subject of P = 2(l + w). Divide by 2: P/2 = l + w. Subtract l: w = P/2 − l.

### Situation: solving equations

**Example — unknown on both sides.** 5x + 3 = 2x + 15. Subtract 2x: 3x + 3 = 15. Subtract 3: 3x = 12. So x = 4. Check: 5 × 4 + 3 = 23 and 2 × 4 + 15 = 23.

**Example — brackets.** 4(x − 2) = 2(x + 5): 4x − 8 = 2x + 10, so 2x = 18 and x = 9.

**Example — fractional coefficient.** x/3 + 4 = 10: x/3 = 6, so x = 18.

**Example — fraction with an expression.** (2x + 1)/5 = 3: multiply by 5, 2x + 1 = 15, so x = 7.

### Situation: forming an equation

**Example — perimeter.** A rectangle is x cm wide and (x + 4) cm long. Its perimeter is 36 cm. So 2x + 2(x + 4) = 36, giving 4x + 8 = 36, 4x = 28 and x = 7. The rectangle is 7 cm by 11 cm.

**Example — ages.** Ana is three times as old as Ben, and their ages add up to 52. If Ben is b, then b + 3b = 52, so b = 13: Ben is 13 and Ana is 39.

### Situation: intervals

**Example — list the integers.** For −3 < x ≤ 2, the integers are −2, −1, 0, 1 and 2 (−3 is not included, 2 is).

**Example — write the interval.** "At least 18 but under 65" is 18 ≤ age < 65.

## Common mistakes

- Adding unlike terms: 3x + 2x² is not 5x³.
- Multiplying only the first term in a bracket: 3(x + 4) is 3x + 12, not 3x + 4.
- Losing a negative sign: −2(x − 3) is −2x + 6.
- Factorising only partly: 6x + 12 = 2(3x + 6) is not fully factorised; it is 6(x + 2).
- Doing an operation to one side only of an equation.
- Mixing up < (open, not included) and ≤ (closed, included).
