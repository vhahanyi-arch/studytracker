# Unit 9 — Sequences and functions

Cambridge Lower Secondary Mathematics, Stage 8, objectives 8As.01, 8As.02 and 8As.03. See [source and scope](README.md).

## Key ideas

### Term-to-term rules — 8As.01

A sequence is a list of numbers (terms) that follow a rule. A term-to-term rule says how to get from one term to the next: "add 3", "multiply by 2", "subtract 2.5", "add 1/4". Sequences can come from numbers or from spatial patterns, such as squares made of matchsticks. Count how much is added to each pattern to find the rule.

### The nth term — 8As.02

A position-to-term rule (the nth term) gives any term from its position n directly. For a linear sequence (the same difference d each time):

nth term = dn + (first term − d).

The coefficient of n is the common difference. It can be positive, negative or a fraction. To test whether a number is in the sequence, set the nth term equal to it and solve: the number is in the sequence only if n is a positive whole number.

### Functions — 8As.03

A function turns each input into exactly one output, by a rule such as "multiply by 3, then add 4". It can be written as a function machine, as a mapping x → 3x + 4, or as an equation y = 3x + 4. To find an input from an output, work backwards with the inverse operations in reverse order: subtract 4, then divide by 3.

## Key facts and formulas

| Fact or formula | What it means | When to use it |
|---|---|---|
| Term-to-term rule | How each term follows from the last | Continuing a sequence. |
| nth term = dn + (first term − d) | Position-to-term rule for a linear sequence | Finding any term, such as the 100th. |
| Common difference d = coefficient of n | Same jump every time | Reading or writing an nth term. |
| x → ax + b; inverse: subtract b, divide by a | A two-step function and its reverse | Finding inputs from outputs. |

## Using the methods in different situations

### Situation: continuing a sequence

**Example — adding.** 5, 8, 11, 14, …: add 3. Next terms: 17, 20.

**Example — multiplying.** 3, 6, 12, 24, …: multiply by 2. Next term: 48.

**Example — fractions.** 1/2, 3/4, 1, 1 1/4, …: add 1/4. Next term: 1 1/2.

**Example — decreasing decimals.** 20, 17.5, 15, 12.5, …: subtract 2.5. Next term: 10.

### Situation: a pattern of shapes

**Example — matchstick squares in a row.** 1 square uses 4 sticks, 2 squares 7, 3 squares 10. Each new square adds 3 sticks, so the nth term is 3n + 1. For 20 squares: 3 × 20 + 1 = 61 sticks.

### Situation: finding the nth term

**Example — increasing.** 5, 8, 11, 14: d = 3, first term 5, so nth term = 3n + (5 − 3) = 3n + 2. Check: n = 1 gives 5.

**Example — decreasing.** 20, 17, 14, 11: d = −3, so nth term = −3n + 23, also written 23 − 3n.

**Example — fractional difference.** 1/2, 1, 1 1/2, 2: d = 1/2, so nth term = 1/2 n + 0 = n/2.

### Situation: using the nth term

**Example — generate terms.** nth term 4n − 7: the first three terms are −3, 1, 5. The 50th term is 4 × 50 − 7 = 193.

**Example — is it in the sequence?** Is 100 in the sequence 3n + 2? 3n + 2 = 100 gives n = 98/3 = 32.67, not a whole number, so no. Is 101? 3n + 2 = 101 gives n = 33, so yes: it is the 33rd term.

### Situation: functions and their inverses

**Example — outputs.** For y = 3x + 4: x = 2 gives 10; x = −1 gives 1; x = 0.5 gives 5.5.

**Example — input from output.** For x → 3x + 4, the output is 19. Work backwards: 19 − 4 = 15, then 15 ÷ 3 = 5. The input was 5.

**Example — find the rule.** A function maps 1 → 5, 2 → 7, 3 → 9. The outputs go up by 2 when the input goes up by 1, so the rule is x → 2x + 3.

## Common mistakes

- Writing n + 3 for the sequence 5, 8, 11. The difference 3 goes with n: 3n + 2.
- Forgetting a negative difference gives a negative coefficient of n.
- Saying a number is in the sequence when n comes out as a fraction or a negative number.
- Undoing a function machine in the original order instead of the reverse order.
