# Chapter 5 — Expressions and formulae

Cambridge Lower Secondary Mathematics, Stage 7 foundations: using letters for numbers, writing and simplifying expressions, and substituting into formulae. See [source and scope](README.md).

## Key ideas

### Letters stand for numbers

In algebra a letter stands for a number you do not know yet, or one that can change. 3n means 3 × n, n² means n × n, and n/2 means n ÷ 2. Write the number before the letter: 3n, not n3.

### Terms, expressions, formulae and equations

A term is a number, a letter, or numbers and letters multiplied together, such as 5, x or 4ab. An expression is terms joined by + or −, such as 3x + 2. A formula connects quantities, such as P = 2l + 2w. An equation is true only for certain values, such as x + 3 = 10.

### Writing expressions from words

Turn each phrase into an operation: "4 more than n" is n + 4; "3 times n, then subtract 2" is 3n − 2; "n shared between 5" is n/5.

### Collecting like terms

Like terms have exactly the same letters: 3a and 5a are like terms; 3a and 3b are not. Add or subtract like terms only: 3a + 2b + 5a − b = 8a + b. Each sign belongs to the term after it.

### Multiplying out a bracket

Multiply every term inside the bracket by the number outside: 3(x + 4) = 3x + 12 and 2(5 − y) = 10 − 2y.

### Substituting into expressions and formulae

Replace each letter with its value, then follow the order of operations. Put negative values in brackets so the signs stay clear: with b = −3, 2 − b = 2 − (−3) = 5.

## Using the methods in different situations

### Situation: writing expressions

**Example.** "7 less than y" is y − 7.

**Example — in context.** Sam has x sweets. Ana has twice as many as Sam. Ana has 2x sweets, and together they have x + 2x = 3x sweets.

**Example — a total cost.** Pens cost p dollars each and a ruler costs 2 dollars. Five pens and a ruler cost 5p + 2 dollars.

### Situation: simplifying

**Example.** 5x + 3 − 2x + 7 = 3x + 10.

**Example — two letters.** 4p + 2q − p + 5q = 3p + 7q.

**Example — multiplying terms.** 2a × 3 = 6a, and 4m × 2n = 8mn.

**Example — a bracket, then like terms.** 2(3y − 1) + 4y = 6y − 2 + 4y = 10y − 2.

### Situation: substituting values

**Example.** With a = 4 and b = −3: 2a + b = 8 + (−3) = 5.

**Example — a product.** With a = 4 and b = −3: ab = 4 × (−3) = −12.

**Example — a square.** With a = 4 and b = −3: a² − b = 16 − (−3) = 19.

### Situation: using formulae

**Example — perimeter.** P = 2l + 2w with l = 7 cm and w = 3 cm: P = 14 + 6 = 20 cm.

**Example — a taxi fare.** C = 5n + 20 gives the cost in dollars for n kilometres. For 6 km: C = 30 + 20 = 50 dollars.

**Example — writing a formula.** A hall charges 100 dollars plus 15 dollars per guest. For g guests the cost is C = 100 + 15g.

## Common mistakes

- Combining unlike terms: 3a + 2b is not 5ab.
- Multiplying only the first term in a bracket: 3(x + 4) is 3x + 12, not 3x + 4.
- Losing the minus sign of a negative value: with b = −3, 2 − b is 5, not −1.
- Confusing 2n and n²: when n = 5, 2n = 10 but n² = 25.
- Forgetting that each sign belongs to the term after it when collecting terms.
