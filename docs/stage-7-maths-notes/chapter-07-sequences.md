# Chapter 7 — Sequences and functions

Cambridge Lower Secondary Mathematics, Stage 7 foundations: term-to-term rules, position-to-term rules, and function machines. See [source and scope](README.md).

## Key ideas

### Sequences and terms

A sequence is a list of numbers that follows a rule. Each number is a term; the first term is in position 1, the second in position 2, and so on.

### Term-to-term rules

A term-to-term rule says how to get from one term to the next. "Start at 3 and add 4" gives 3, 7, 11, 15, ... A sequence can also go down (50, 44, 38, ... subtract 6) or multiply (2, 6, 18, 54, ... multiply by 3).

### Linear sequences

In a linear sequence the difference between terms is always the same. 5, 8, 11, 14 has a difference of 3. The square numbers 1, 4, 9, 16 are not linear: their differences are 3, 5, 7.

### Position-to-term rules

A position-to-term rule gives any term from its position n, without listing the terms before it. The rule 4n − 1 gives 3, 7, 11, 15, ... and its 10th term is 4 × 10 − 1 = 39. For a linear sequence, the number in front of n is the difference between terms.

### Function machines

A function machine applies operations to an input to give an output: input 5 → × 2 → + 3 → output 13. To go backwards from an output, reverse the order and use inverse operations: output 13 → − 3 → ÷ 2 → input 5. The same function can be written x → 2x + 3.

## Key facts and formulas

| Fact or method | What it means | When to use it |
|---|---|---|
| Term-to-term rule | How to get the next term | Continuing a sequence. |
| Constant difference | The sequence is linear | Recognising linear sequences. |
| nth term = (difference) × n + (adjustment) | A position-to-term rule | Finding any term directly. |
| Check the rule with n = 1 | The first term must match | Testing a position-to-term rule. |
| Reverse order, inverse operations | Working a function machine backwards | Finding an input from an output. |

## Using the methods in different situations

### Situation: continuing sequences

**Example.** 5, 8, 11, 14, ... adds 3 each time. The next two terms are 17 and 20.

**Example — going down.** 50, 44, 38, ... subtracts 6. The next term is 32.

**Example — multiplying.** 2, 6, 18, 54, ... multiplies by 3. The next term is 162.

### Situation: position-to-term rules

**Example — terms from a rule.** The rule 3n + 2 gives 5, 8, 11, 14, ... Its 20th term is 3 × 20 + 2 = 62.

**Example — a rule from terms.** 4, 7, 10, 13, ... has a difference of 3, so the rule starts 3n. When n = 1, 3n = 3, but the term is 4, so the rule is 3n + 1.

**Example — is it in the sequence?** Is 100 a term of 3n + 1? 3n + 1 = 100 gives 3n = 99 and n = 33, a whole number, so yes: it is the 33rd term.

**Example — not in the sequence.** Is 50 a term of 4n − 1? 4n − 1 = 50 gives 4n = 51, and 51 ÷ 4 is not a whole number, so no.

### Situation: function machines

**Example.** Input 6 → × 4 → − 5. The output is 24 − 5 = 19.

**Example — backwards.** A machine does × 2 then + 3, and the output is 23. Reverse it: 23 − 3 = 20, then 20 ÷ 2 = 10. The input was 10.

**Example — a table.** For x → 2x + 3, the inputs 1, 2 and 3 give the outputs 5, 7 and 9.

### Situation: patterns

**Example — matchsticks.** A row of squares made of matchsticks uses 4, 7, 10, ... sticks for 1, 2, 3, ... squares. The difference is 3, so the rule is 3n + 1. Ten squares need 3 × 10 + 1 = 31 sticks.

## Common mistakes

- Treating the term-to-term rule as the position-to-term rule: "add 3" means the rule starts 3n, not n + 3.
- Not checking the rule against the first term.
- Working a function machine backwards in the same order instead of the reverse order.
- Mixing up a term's position with its value.
- Assuming every sequence is linear without checking the differences.
