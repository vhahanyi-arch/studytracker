# Chapter 6 — Equations and inequalities

Cambridge Lower Secondary Mathematics, Stage 7 foundations: solving simple equations, forming equations from words, and inequalities on a number line. See [source and scope](README.md).

## Key ideas

### An equation is a balance

The two sides of an equation are equal, like the two pans of a balanced scale. Whatever you do to one side, do to the other, and the equation stays true.

### Solving with inverse operations

Undo what has been done to the letter, using inverse operations: + undoes −, × undoes ÷, and the other way round. Undo the last operation first. In 3x − 5 = 16, the x was multiplied by 3 and then 5 was taken away, so add 5 first, then divide by 3.

### Equations with brackets

Either divide both sides by the number outside the bracket, or multiply out the bracket first: 2(x + 3) = 18 gives x + 3 = 9, so x = 6.

### Forming equations

Choose a letter for the unknown, write each fact as an expression, and set it equal to what you know. "I think of a number, multiply it by 3 and add 4. The answer is 25" becomes 3n + 4 = 25.

### Checking a solution

Substitute your answer back into the original equation: if x = 7 in 3x − 5 = 16, then 21 − 5 = 16, which is true.

### Inequalities

< means "is less than", > "is greater than", ≤ "is less than or equal to" and ≥ "is greater than or equal to". On a number line, x > 2 is drawn with an open circle at 2 (2 is not included) and an arrow to the right; x ≤ 2 has a filled circle at 2. Simple inequalities are solved like equations: x + 3 < 10 gives x < 7.

## Key facts and formulas

| Fact or method | What it means | When to use it |
|---|---|---|
| Do the same to both sides | Keeps the equation balanced | Every equation. |
| + and −, × and ÷ | Inverse pairs | Undoing operations on the letter. |
| Undo the last operation first | Work backwards | Two-step equations. |
| Substitute to check | Both sides must be equal | After solving. |
| Open circle: < or >; filled circle: ≤ or ≥ | Whether the end value is included | Number lines for inequalities. |

## Using the methods in different situations

### Situation: one-step and two-step equations

**Example.** x + 9 = 15, so x = 15 − 9 = 6.

**Example — multiplication.** 4x = 28, so x = 28 ÷ 4 = 7.

**Example — two steps.** 3x − 5 = 16. Add 5: 3x = 21. Divide by 3: x = 7.

**Example — a division.** x/4 + 2 = 5. Subtract 2: x/4 = 3. Multiply by 4: x = 12.

### Situation: equations with brackets

**Example.** 2(x + 3) = 18. Divide by 2: x + 3 = 9, so x = 6.

**Example — expanding first.** 5(y − 1) = 35. Expand: 5y − 5 = 35. Add 5: 5y = 40, so y = 8.

### Situation: forming equations from words

**Example — think of a number.** 3n + 4 = 25. Subtract 4: 3n = 21, so n = 7.

**Example — a rectangle.** A rectangle is w cm wide and w + 5 cm long, and its perimeter is 34 cm. 2w + 2(w + 5) = 34, so 4w + 10 = 34, 4w = 24 and w = 6. The rectangle is 6 cm by 11 cm (check: 6 + 11 + 6 + 11 = 34).

**Example — angles.** The angles of a triangle are x, 2x and 3x. They add to 180°: 6x = 180, so x = 30 and the angles are 30°, 60° and 90°.

### Situation: inequalities

**Example.** x + 4 > 9, so x > 5.

**Example — multiplication.** 3x ≤ 12, so x ≤ 4.

**Example — listing integers.** The integers n with −3 ≤ n < 2 are −3, −2, −1, 0 and 1. (−3 is included; 2 is not.)

## Common mistakes

- Doing an operation to one side only.
- Undoing in the wrong order: in 3x − 5 = 16, add 5 before dividing by 3.
- Changing a sign by mistake when moving a term: from x + 9 = 15, x is 6, not 24.
- Including the end value for < or >, or leaving it out for ≤ or ≥.
- Forgetting to check the answer in the original equation.
