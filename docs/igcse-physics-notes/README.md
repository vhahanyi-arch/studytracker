They follow the syllabus record in [lib/physics-syllabus.ts](../../lib/physics-syllabus.ts), which lists every Core and Supplement objective of Cambridge IGCSE Physics 0625. The notes are written in our own words; no Cambridge text, figures or past-paper questions are copied into them.

Each unit has the same shape: a concept summary per syllabus section, a formula table (formula, symbols and units, when to use it, Core or Supplement), worked examples showing each formula in different kinds of question, and a list of exam checks. Supplement (Extended) content is labelled so a Core student can skip it.

Units follow the syllabus: m/s, m/s², N/kg, kg/m³, J/(kg °C). g is taken as 9.8 N/kg unless a question gives another value. Worked-example arithmetic was checked by script before publishing.

To change a note, edit the markdown here and run `pnpm notes`. `tests/notes/content.test.ts` fails if the generated module and these files disagree, if any unit lacks notes, or if a unit's notes do not cite each of its syllabus sections.
